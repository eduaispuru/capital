# Capital

Editor de Markdown para escribir literatura: el texto se ve formateado mientras escribís, dividido en páginas de libro.

Abrila en Chrome o Edge y elegí **Instalar** en la barra de direcciones para usarla como app en Windows o ChromeOS. Tus escritos quedan en tu propia carpeta; la app no los sube a ningún lado.

Usa [Vditor](https://github.com/Vanessa219/vditor) (MIT) como editor y fuentes de Google Fonts (OFL).
